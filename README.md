# Player-Roaster-
Player Roaster by Microsoft EXCEL 
🎮 Esports Player Roster Analytics Dashboard
📌 Overview
The Player Roster Dashboard is an interactive Microsoft Excel analytics solution designed to transform raw esports player data into strategic actionable insights. It analyzes competitive gaming talent across global regions, title breakdown, years of experience, and social media engagement correlated with tournament standings.

📊 Core Performance Metrics & KPIs
🎮 High-Level Summary Cards

🔍 Key Insights & Analysis Modules
🌐 1. Regional & Global Distribution
Dominant Region: Asia leads global talent concentration with 142 players, followed by Europe (77), North America (23), South America (14), Middle East (14), and Oceania (2).

Geographic Mapping: Visualizes player density across global territories, identifying top country representations (e.g., China, USA, Brazil).

🏆 2. Experience & Player Longevity
Veterans of the Scene: Identifies the top most experienced esports competitors, led by veteran figures like Xiaotian (36 years/seasons), Hikaru (22), Magnus Carlsen (20), Classic (14), alongside staples like Faker, LOWHIGH, and Serral.

🎯 3. Game-Wise Player Allocation
Top Titles by Roster Count: Overwatch 2 and Teamfight Tactics lead player counts with 16 players each, followed closely by major competitive titles (League of Legends, Counter-Strike 2, Dota 2, Valorant, Rainbow Six Siege, and Honor of Kings) at 15 players each.

Battle Royale & Mobile Titles: Tracks active player counts across PUBG Mobile, Free Fire, Call of Duty: Warzone, and Apex Legends.

📲 4. Social Engagement vs. Tournament Performance
Correlates social media follower metrics against final tournament placement positions (1st Place: 15,894 followers, 2nd Place: 8,214 followers, 3rd Place: 14,892 followers).

🛠️ Dashboard Features & Interactivity
Dynamic Slicers: Filter the entire sheet seamlessly by Experience Level, Game Title, or individual Player ID (e.g., EWC2025_001).

Custom UI Design: Sleek, neon-themed dark mode interface crafted with clear visual hierarchy, custom icon header cards, and responsive map visualizations.

Built in Microsoft Excel: Utilizes Advanced Formulas, Pivot Tables, Pivot Charts, and Dynamic Data Slicers.
